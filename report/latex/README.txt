Governing Execute — Alejandro Garibotti

Compile this self-contained directory with:
  tectonic main.tex
or XeLaTeX, BibTeX, then XeLaTeX twice.

Generated counts and vector figures are included. No Python or model server is
needed for a paper-only build. A first TeX build can require package downloads.
The full project regenerates figures with scripts/build_paper.py.

layout.sty is a local adaptation of the supplied Apart DOCX section roles and
page geometry, not an official Apart class. Fonts retain their included OFL.
The manuscript is AI-assisted and awaits Alejandro Garibotti's review.
