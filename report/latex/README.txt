An Acceptance Contract for Delegating Agent Brokers — Alejandro Garibotti

Compile this self-contained directory with:
  tectonic main.tex
or XeLaTeX, BibTeX, then XeLaTeX twice.

Generated tables and licensed fonts are included. No Python or model server is
needed for a paper-only build. A first TeX build can require package downloads.
The full project regenerates evidence tables with scripts/build_paper.py.

layout.sty adapts the Apart DOCX section roles and page geometry; it is not an
official Apart class. The paper contains an LLM assistance statement.
