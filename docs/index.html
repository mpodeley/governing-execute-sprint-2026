An Acceptance Contract for Delegating Agent Brokers

Alejandro Garibotti

Can a queued request keep authority its parent has lost? Can two workers spend the same shared budget? A concrete contract for checking what survives delegation.

The deliverable

Four records. One accountable chain.

Connect each committed effect to the mandate that authorizes it. Retain the decision and reconcile its actual resource consequences.

1. Mandate

Owner, purpose, resources, shared budget, expiry and review route.

2. Grant

Identity, parent, narrowed constraints, version and current status.

3. Decision

Request, actor, intended effect, cost, current lineage and reason.

4. Outcome

Effect or refusal, ledger change and persistent consequences.

Offline credential attenuation constrains each grant. Enforcing a shared sibling pool also needs shared consumption state or nonoverlapping reservations. This contract builds on capability security and hierarchical quotas.

Local spending removes only shared accounting at commit. Stale ancestry removes only ancestor expiry and revocation checks at commit. These deliberate component removals identify failure signatures.

Passing these authored probes is conformance evidence. It is not a measured security rate or a comparison with deployed products. Full mediation and independently observed outcomes remain integration requirements.

The safety boundary

An authorized action can still cause harm.

Each retained trace offers ten hazardous work actions and ten safe auxiliary actions. Work is initially authorized. Change when a report arrives and when a correct reviewer responds.

Hold work on report receipt
3 / 10
Hazardous effects committed
Wait for the decision to stop work
9 / 10
Hazardous effects committed

Both policies commit all ten auxiliary actions. A late report cannot undo earlier effects.

These are deterministic timing cases, not observed reporting behavior. The display reads the retained data; it runs no agents.

From incident to acceptance question

Unsanctioned coordination motivates a channel inventory. Out-of-scope work motivates request-bound authority. Credential withdrawal motivates tests of dependent and queued effects.

En español

Un contrato para comprobar qué autoridad sobrevive a la delegación.

Si dos agentes comparten un presupuesto, sus límites individuales no alcanzan para conservarlo. Si se revoca al padre, ni la cola ni un hermano deben conservar esa autoridad. Y el gasto anterior debe seguir registrado.

El paper de Alejandro Garibotti convierte estas obligaciones en pruebas reutilizables. También incorpora reportes tardíos, ausentes y sin respuesta: cumplir un mandato no garantiza que ese mandato sea seguro.
